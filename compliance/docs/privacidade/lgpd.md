# LGPD na prática

## Para quem desenvolve

- **Minimização**: colete só os dados necessários para a finalidade.
- **Base legal**: todo tratamento tem uma base legal registrada.
- **Retenção**: defina por quanto tempo o dado é guardado e como é eliminado.
- **Direitos do titular**: o sistema permite consultar, corrigir e eliminar os dados?
- **Logs**: não registre dados pessoais em logs; mascare quando inevitável.

## Privacy by design

| Fase | Pergunta |
|------|----------|
| Desenho | Precisamos mesmo deste dado? |
| Construção | Está criptografado em trânsito e em repouso? |
| Teste | Usamos dados sintéticos ou anonimizados? |
| Operação | Quem acessa e como isso é auditado? |

!!! danger "Incidente com dados pessoais"
    Acione imediatamente o time de segurança e o encarregado de dados (DPO).
