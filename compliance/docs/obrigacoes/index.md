# Obrigações

| Fonte | Tipo | Impacto em tecnologia |
|-------|------|-----------------------|
| LGPD (Lei 13.709/2018) | Lei | Tratamento de dados pessoais, direitos do titular, incidentes |
| ISO/IEC 27001 | Norma (referência) | Sistema de gestão de segurança da informação |
| Política de segurança da informação | Política interna | Acesso, criptografia, uso aceitável |
| Política de desenvolvimento seguro | Política interna | SDLC, scans, revisão de código |
| Regulação setorial | Regulação | Depende do setor (ex.: financeiro, saúde) |

Cada obrigação é mapeada para um ou mais [controles](../controles/index.md).
