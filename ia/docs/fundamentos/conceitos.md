# Conceitos

Machine learning (ML)
:   Modelos que aprendem padrões a partir de dados para prever ou classificar.

LLM
:   Large Language Model: modelo de linguagem treinado em grandes volumes de texto, capaz de
    gerar e interpretar linguagem natural.

Prompt
:   A instrução e o contexto enviados ao modelo.

Token
:   Unidade de texto processada pelo modelo; base da cobrança e do limite de contexto.

RAG
:   Retrieval-Augmented Generation: buscar documentos relevantes e incluí-los no contexto para
    respostas fundamentadas.

Agente
:   Aplicação em que o modelo decide e executa ações por meio de ferramentas, em ciclos.

Alucinação
:   Resposta plausível, porém incorreta ou sem fundamento.
