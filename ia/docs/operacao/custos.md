# Custos

- Escolha o **menor modelo** que atende à qualidade exigida (medida na avaliação).
- Use **cache de prompt** para contextos repetidos.
- Limite o tamanho do contexto: recupere só os trechos relevantes.
- Defina **orçamento por aplicação** com alertas de consumo.
- Processamento em lote, quando não houver urgência, costuma ser mais barato.
