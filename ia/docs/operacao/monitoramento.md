# Monitoramento

| Métrica | Por quê |
|---------|---------|
| Latência (p50/p95) | Experiência do usuário |
| Taxa de erro / timeouts do provedor | Disponibilidade |
| Tokens por requisição | Custo e limites de contexto |
| Avaliação de qualidade em amostras | Regressões silenciosas |
| Taxa de recusa / feedback negativo | Problemas de prompt ou de cobertura |

Alertas seguem o padrão do
[Golden Path para Serviços](http://localhost:3000/docs/default/component/golden-path-servicos/4-producao/observabilidade/).
