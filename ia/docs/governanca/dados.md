# Dados e privacidade

- Use apenas **ferramentas e provedores aprovados**; verifique retenção e uso dos dados pelo provedor.
- Não envie dados **confidenciais ou restritos** a ferramentas não aprovadas para essa classe
  (veja a [classificação](http://localhost:3000/docs/default/component/wiki-compliance/privacidade/classificacao/)).
- Mascare ou remova dados pessoais antes de enviar ao modelo, quando possível.
- Registre os prompts e respostas em logs com o mesmo cuidado de qualquer dado pessoal.
