# Papéis

| Papel | Responsabilidades principais |
|-------|------------------------------|
| **Time dono (owner)** | Construir, operar e documentar seus componentes; responder a incidentes |
| **Tech lead** | Qualidade técnica, decisões locais, ADRs do time |
| **Product owner** | Prioridade, valor e aceite das entregas |
| **Arquitetura** | Princípios, padrões e decisões transversais |
| **Plataforma** | Golden paths, CI/CD, Backstage, infraestrutura compartilhada |
| **Segurança** | Políticas, controles, resposta a incidentes de segurança |
| **Compliance / Riscos** | Obrigações regulatórias, controles e evidências |

!!! tip "Ownership no catálogo"
    O owner de cada componente está no Backstage (`spec.owner`). Componente sem owner é um risco.
